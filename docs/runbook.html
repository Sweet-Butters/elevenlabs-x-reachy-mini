Hello World AI 해커톤 · 2026.10.31 토 · 13:00–17:00 · 진행자용

1 · 출발 전

  • 폰 핫스팟 데이터·배터리 확인. 행사장 Wi-Fi 우선, 안 되면 폰 핫스팟.
  • 노트북·로봇 충전, 충전기·멀티탭 챙기기.
  • 외부 스피커 연결·볼륨 점검.
  • 로봇이 핫스팟에 붙는지 확인. MP3·모델 파일 사전 준비.

2 · 도착 후 세팅 5단계

  1. 로봇 조립·전원·데몬 확인. 폰으로 reachy-mini-ap에 접속 → http://reachy-mini.local:8000/settings에서 행사장 Wi-Fi 연결. 안 되면 폰 핫스팟 사용. 노트북도 같은 망에 연결.
  2. 조립 직후: .venv\Scripts\python.exe scripts\robot_check.py. 연결 실패 시 공유기 접속 기기 목록에서 IP 확인 → .venv\Scripts\python.exe scripts\robot_check.py --host 192.168.45.225 (집 Wi-Fi 예시).
  3. MP3 점검: .venv\Scripts\python.exe scripts\play_lines.py --list; 타이머·환영 MP3도 확인.
  4. 입구 카메라 각도 점검: .venv\Scripts\python.exe scripts\welcome_mode.py --robot --preview → Q로 종료.
  5. 손인사 준비: .venv\Scripts\python.exe scripts\make_wave_lines.py와 yolo11n-pose.onnx 확인. 통합 앱 시작: .venv\Scripts\python.exe scripts\riichi.py --robot --mode welcome. 자동 검색 실패 시 끝에 --host 로봇IP 추가.

상황정확한 말 / 키
질문“리치야, 제출 마감 언제야?” · 답변 뒤 5초 내 후속 질문 1번
손인사로봇 카메라 앞에서 손을 높이 들고 좌우로 흔들기 (대화·환영)
대화 → 환영“리치야, Welcome Mode 시작” / F3
환영 → 대화“웰컴 모드 종료” / F1
대화 → 타이머“리치야, 타이머 모드 활성화” / F2
3분 즉시 시작“Hey Reachy, timer 3 minutes” (대화 중)
타이머 → 대화“타이머 모드 해제” / F1
타이머 조작Enter/Space 시작·다음, p 일시정지·재개, r 초기화, k/e 다음 발표 한국어/영어, n 다음 길이, q 종료

문자 점검: .venv\Scripts\python.exe scripts\riichi.py --text에서 /f1·/f2·/f3·/enter·/quit.

대화 기본값은 이름으로 시작한 말만 답함. “리치야”만 말하면 “네!” 후 6초 대기. --followup-seconds 0 후속 질문 끄기, --no-wake-word 기존 상시 대화, --no-wave 손인사 끄기, --wave-cooldown 15 간격 조절. 타이머·환영 종료 명령은 이름 없이.

5 · 문제가 생기면

  • 로봇 연결 실패: 전원·같은 Wi-Fi·데몬 확인. reachy-mini.local이 안 잡히면 공유기 기기 목록에서 IP를 확인하고 위 점검 명령에 --host 지정. 계속 실패하면 노트북만 사용: .venv\Scripts\python.exe scripts\riichi.py 또는 .venv\Scripts\python.exe scripts\welcome_mode.py --preview.
  • 인터넷 끊김: 대화·음성 인식은 중단. 저장된 MP3 재생 .venv\Scripts\python.exe scripts\play_lines.py 6; 3분 결선은 .venv\Scripts\python.exe scripts\pitch_timer.py --lang ko. 환영 MP3·모델이 준비됐다면 .venv\Scripts\python.exe scripts\welcome_mode.py --preview도 동작.
  • 음성 전환 안 됨: F1 대화 / F2 타이머 / F3 환영. 타이머에서는 Enter로 발표 시작.
  • 엉뚱한 답: 진행자가 즉시 정정하고 필요한 모드로 전환. 모르는 사실은 운영진에게 연결.
  • 소리가 작음: --robot 대화·환영은 로봇 스피커, 노트북 모드는 노트북 출력·외부 스피커 확인.

오프닝에 알리기: 행동강령상 허락 없는 촬영 금지. 리치는 카메라 프레임·영상을 저장하거나 업로드하지 않고 얼굴 인식도 하지 않습니다.
